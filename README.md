#HCL-Hackon

This repository contains two projects:

1. Customer Churn Predictor

A machine learning model designed to identify customers likely to stop using a company's services.
Key components include:

Techniques for handling imbalanced datasets

Model training and evaluation

Use of metrics such as Precision, Recall, F1-Score, and ROC-AUC

Explanation of the Confusion Matrix and ROC Curve

2. Mini RAG-Powered AI Assistant

A basic Retrieval-Augmented Generation (RAG) system built using Ollama.
Features include:

Document ingestion and embedding generation

Retrieval of relevant context using vector similarity search

Question answering based on a custom document corpus

This repository demonstrates practical applications of machine learning and RAG-based AI systems.
